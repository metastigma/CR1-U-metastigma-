Local fonts for Chaos Rings HD

Put one or more TrueType / OpenType font files in this folder:
  .ttf  - TrueType
  .otf  - OpenType
  .ttc  - TrueType Collection

The game reads fonts only from this folder beside the executable. It does not
search the Windows, macOS, Linux or Android system font directories.

Open Options -> Game -> Font and use Left / Right to choose a file. The choice
is saved in settings.ini; a restart is not required.

For Japanese, Chinese and Korean text, choose a font (or TTC face) with the
required CJK glyphs. If no usable fonts are present, the game uses its built-in
bitmap font.
